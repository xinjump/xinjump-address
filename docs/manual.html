发货信息解析

图文操作手册 · 只需三步，把杂乱的收货信息变成整理好的清单

免安装 · 打开网页即用 数据不出本机 支持多条地址一起粘贴

这个工具是做什么的？

把从微信、订单、Excel 里复制来的一段段收货信息（地址、姓名、电话、数量混在一起），自动整理成一张清晰的表格：谁收货、电话多少、寄到哪里、发什么货、什么规格、发多少。

举例：把下面这样的原始文字粘进工具里——
广东省广州市天河区示例大道1103张三13800138000 2箱
工具就能自动认出：张三 的电话是 13800138000，地址是 广东省广州市天河区示例大道1103，发 玉露香梨 12颗 / 2箱。

三步上手

1

打开工具，认识界面

  • 页面中间的大白框是输入框，用来粘贴收货信息。
  • 输入框下面有两个按钮：删除（清空重来）和解析（开始识别）。
提示：不用安装任何软件，浏览器打开就能用。
2

把收货信息粘贴进输入框

  • 直接把复制好的文字粘贴进来，一行一个收货人，也可以多行写同一个人。
  • 不用管格式对不对、顺序对不对，工具会自动辨认姓名、电话、地址、数量。
  • 写错了没关系，点删除一键清空，重新粘贴。
支持的写法非常宽松：姓名在前在后、电话写在中间、带「收件人：」等标签的，都能识别（见下方格式表）。
3

点击「解析」，查看结果

  • 点击蓝色的解析按钮，会弹出一个「解析结果」窗口。
  • 窗口里的表格就是整理好的信息：蓝色的是收货人和电话，红色的是数量，一眼就能看到。
  • 同一个收货人发多种货时，姓名、电话、地址会自动合并，下面并列多条明细。
看完点右下角「关闭」即可；也可以直接点弹框外的灰色区域，或按 Esc 关闭。

复制结果发给同事

在解析结果弹框里点左下角的复制按钮，结果会以纯文本复制到剪贴板，直接粘贴到微信、备忘录、Excel 里都行：

常见问题

识别结果有错误怎么办？

目前结果以展示为主，如个别字段识别不准，可在复制出的文本里手动修改后再发送；也可以调整原始文字（比如在姓名和地址之间加个空格）后重新解析。

忘记写数量了会怎样？

数量会默认按 1箱 处理，商品默认玉露香梨、规格默认 12颗，不会丢失这一条记录。

一次能贴多少条？

没有严格限制，几十条一起粘贴也没问题。建议不同收货人之间用空行隔开，识别更准。

有快捷键吗？

有：在输入框里按 Ctrl + Enter（Mac 为 ⌘ + Enter）直接解析；弹框打开时按 Esc 关闭。

数据安全吗？

安全。所有解析都在你自己的浏览器里完成，不会上传到任何服务器，也不会保存历史记录；关闭页面后输入的内容即消失。
