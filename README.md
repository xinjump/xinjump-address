# 发货信息整理单

一个零依赖的纯前端工具，用于整理「发货数量与规格」以及「收货地址与联系人信息」。

把从聊天记录、Excel、订单等地方复制来的杂乱文本，一键识别成结构化信息，并支持导出带样式的 Excel、复制结果、打印。

## 功能特性

- **多收货人管理**：一次可维护多个收货人，每个收货人独立包含联系人、电话、地址和发货明细。
- **智能解析**：粘贴一段文本，自动识别收货人、联系电话、收货地址和发货数量。
- **多规格明细**：支持同一收货人多条明细，品名可自动归类（如「梨」归为「玉露香梨」）。
- **导出 Excel**：导出带样式的 `.xls` 文件（标题、表头着色、按收货人分组、列宽与行高优化、关键信息醒目）。
- **复制 / 打印**：一键复制整理结果文本，或打印专用版式（含签收栏）。
- **多单据**：支持新建、重命名、复制、删除单据。
- **本地持久化**：数据保存在浏览器 `localStorage`，刷新不丢失，不会上传服务器。
- **夜间模式**：支持深色主题。

## 智能解析支持的格式

解析器能识别以下常见输入格式（可混用）：

| 场景 | 示例输入 | 识别结果 |
|---|---|---|
| 地址 + 姓名 + 电话粘连 | `广东省广州市天河区示例大道1号张三13800138000 2箱` | 张三 / 13800138000 / 广东省广州市… / 2箱 |
| 单字姓名 | `…菜鸟驿站，李四13900139000 2件` | 李四 / 13900139000 / …驿站 / 2件 |
| 电话在姓名前 | `13700137000 王女士` | 王女士 / 13700137000 |
| 尊称姓名 | `赵先生，13600136000，地址：南京市鼓楼区示范路16号 1件` | 赵先生 / 13600136000 / 南京市… / 1件 |
| 标签式字段 | `邮寄地址：…，电话：…姓名：刘梅 3件` | 刘梅 / 电话 / 地址 / 3件 |
| 多行标签式 | `收件人:…\n手机号码:…\n所在地区:…\n详细地址:…` | 自动拼接完整地址 |
| 品名在数量前 | `苹果10箱梨5箱` | 苹果 10箱 + 玉露香梨 5箱 |
| 数量 + 单位 + 品名 | `3件梨 1件苹果` | 玉露香梨 3件 + 苹果 1件 |
| 中文数字数量 + 规格 | `一箱18颗` | 数量 1箱 + 规格 18颗 |
| 空行分组 / 多地址 | 多段地址文本 | 自动拆分为多个收货人 |

默认商品信息：品名「玉露香梨」、规格「12枚」、单位「箱」，均可手动修改；不带品名的数量默认归为玉露香梨。

## 使用方式

1. 直接用浏览器打开 `index.html`，或在本目录启动任意静态服务器（如 `npx serve`）。
2. 点击「✨ 智能解析」，粘贴一段或多段收货文本，自动生成多个收货人及明细。
3. 手动增删收货人、明细行，或修改任意字段。
4. 通过顶部按钮「复制结果 / 导出 Excel / 打印」输出。

## 技术说明

- 纯 HTML / CSS / JavaScript，无第三方依赖。
- 数据持久化使用浏览器 `localStorage`。
- 导出文件为 HTML 表格格式的 `.xls`（Excel 可直接打开并保留样式）。
