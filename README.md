# 发货信息解析

一个零依赖的纯前端工具，把从聊天记录、Excel、订单等地方复制的杂乱文本，一键解析成结构化的收货信息。

## 功能特性

- **极简界面**：一个大输入框 + 「删除」「解析」两个按钮。
- **弹框展示结果**：点击「解析」弹出结果弹框，列出收货人、联系电话、收货地址、商品、规格、数量。
- **复制 / 关闭**：弹框内可一键复制解析结果，也可通过按钮、右上角 ✕、点遮罩或 `Esc` 关闭。
- **多地址多规格识别**：一次粘贴多段收货信息，自动拆分并识别。
- **图文操作手册**：首页提供「操作手册」入口，图文并茂说明用法，可随时返回首页。

## 智能解析支持的格式

解析器能识别以下常见输入格式（可混用）：

| 场景 | 示例输入 | 识别结果 |
|---|---|---|
| 地址 + 姓名 + 电话粘连 | `广东省广州市天河区示例大道1号张三13800138000 2箱` | 张三 / 13800138000 / 广东省广州市… / 2箱 |
| 单字姓名 | `…菜鸟驿站，李四13900139000 2件` | 李四 / 13900139000 / …驿站 / 2箱 |
| 电话在姓名前 | `13700137000 王女士` | 王女士 / 13700137000 |
| 尊称姓名 | `赵先生，13600136000，地址：南京市鼓楼区示范路16号 1件` | 赵先生 / 13600136000 / 南京市… / 1箱 |
| 标签式字段 | `邮寄地址：…，电话：…姓名：刘梅 3件` | 刘梅 / 电话 / 地址 / 3箱 |
| 多行标签式 | `收件人:…\n手机号码:…\n所在地区:…\n详细地址:…` | 自动拼接完整地址 |
| 品名在数量前 | `苹果10箱梨5箱` | 苹果 10箱 + 玉露香梨 5箱 |
| 数量 + 单位 + 品名 | `3件梨 1件苹果` | 玉露香梨 3箱 + 苹果 1箱 |
| 中文数字数量 + 规格 | `一箱18颗` | 数量 1箱 + 规格 18颗 |
| 空行分组 / 多地址 | 多段地址文本 | 自动拆分为多个收货人 |

## 归一化规则

- **品名**：未识别时默认「玉露香梨」；`梨 / 香梨 / 梨子` 自动归为「玉露香梨」。
- **规格**：默认「12颗」；`枚` 统一显示为 `颗`（如 `18枚` → `18颗`）。
- **数量**：未识别时默认 `1`；`件` 统一显示为 `箱`。

## 复制格式

弹框内点击「复制」，按以下格式复制：

```
【收货人 1】
收货人：王女士
联系电话：13700137000
收货地址：北京市延庆区示范街16号
1. 玉露香梨/12颗/1箱
2. 苹果/12颗/1箱

【收货人 2】
收货人：赵先生
联系电话：13600136000
收货地址：南京市鼓楼区示范路16号
1. 玉露香梨/12颗/1箱
```

## 使用方式

1. 直接用浏览器打开 `index.html`，或在本目录启动任意静态服务器（如 `npx serve`）。
2. 在大输入框粘贴一段或多段收货文本。
3. 点击「解析」，弹框展示解析结果。
4. 点击「复制」复制结果，或「关闭」关闭弹框。
5. 点击首页右上角的「操作手册」可查看图文使用说明。
